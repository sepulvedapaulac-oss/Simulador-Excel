Lección 3.1 · Documentar

Qué debe tener un diccionario de variables

El diccionario le dice a la IA, y a cualquier lector, qué significa cada columna. Abre cada elemento.

Elementos revisados 0 / 5

Usa nombres estables y fáciles de citar en una instrucción: codigo, area, horas_extra, haberes_total.

Evita “Total 2” o “Columna nueva”: la IA no sabe a qué se refieren.

Una frase que precise el alcance. Es el elemento que más evita errores de interpretación.

bonos: bonos variables del mes (producción, metas); excluye la gratificación.

Indica la unidad y el formato. Las horas en decimal (7,5) no son lo mismo que en hh:mm (7:30).

horas_extra: número decimal, horas del mes. periodo: AAAA-MM.

Lista las categorías y los rangos esperados. Sirven para detectar errores y para que la IA no invente categorías.

area: Ventas, Operaciones, Finanzas, Planta, Bodega. dias_trab: 0 a 30.

Indica el sistema o registro de origen. Permite verificar un dato cuando el análisis muestra algo inesperado.

horas_extra: registro de asistencia aprobado. sueldo_base: contrato vigente.

Aplicación en tu trabajo

Arma tu plan de preparación de datos

Piensa en un análisis que necesites hacer. Completa cada elemento, genera tu plan, compáralo con la respuesta modelo y cópialo.

Idea clave de la respuesta modelo: una pregunta concreta, solo las variables necesarias, protección con códigos y agregados, y una base cuadrada con el sistema antes de entregarla. Revisa la explicación bajo cada elemento.
